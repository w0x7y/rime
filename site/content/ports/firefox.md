# firefox color

the browser's tabs, toolbar, address bar, menus and sidebars, through mozilla's [firefox color](https://color.firefox.com). the tab strip and sidebars take the darker chrome shade, the selected tab and toolbar the background, as in the editors.

open a variant in firefox:

- [rime](/files/general/firefox/rime.html)
- [rime glacier](/files/general/firefox/rime-glacier.html)
- [rime aurora](/files/general/firefox/rime-aurora.html)
- [rime abyss](/files/general/firefox/rime-abyss.html)
- [rime frost](/files/general/firefox/rime-frost.html)

each link opens firefox color with the variant loaded. install the firefox color extension when it asks, and the theme applies. save it there to keep it.
