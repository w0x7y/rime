# discord

a theme for discord, through [betterdiscord](https://betterdiscord.app) or [vencord](https://vencord.dev). the chat sits on the background, the server and channel lists on the darker chrome shade, and menus and popouts on the popup shade.

{{downloads}}

## install

open **settings → themes → open themes folder** (both mods have it), save the theme file there and turn it on in the same list. with vencord you can also add its raw link as an online theme:

```text
https://raw.githubusercontent.com/w0x7y/rime/main/general/discord/{{slug}}.theme.css
```

## notes

- the dark variants color discord's dark modes (dark, darker and midnight), and rime frost its light mode. set discord's **appearance** to match.
- discord renames its color variables now and then, so an update can leave parts of the app in discord's own colors for a while.
- profiles with their own colors keep them.
