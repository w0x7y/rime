# a colder colorscheme.

cool grays and soft, cold accents. five variants, for neovim, vs code, zed, nine terminals, apps and the rest.

[install](/ports) · [github](https://github.com/w0x7y/rime) · `{{version}}`

## variants

glacier has a lighter background, and aurora and abyss darker ones.

## ports

## make it yours

rime is 16 colors in a json file and one python script that writes every port from them. [change a color](/docs/customizing) in your neovim config, [make a variant](/docs/customizing#your-own-variant), or [port it](/docs/porting) somewhere new. pull requests are welcome.
